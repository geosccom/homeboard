Privacy policy

Family Dashboard is a personal, self-hosted application used by a single household. Last updated: November 2026.

Data accessed

With the account owner’s consent, the application requests read-only access to Google Drive (drive.readonly). It reads file names, folders, thumbnails and file contents only to display them on the household’s own screens.

Storage

Access tokens and thumbnail caches are stored only on a computer inside the owner’s home. No data is sent to the developer or to any third party, and nothing is sold, shared or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions; the cached data on the home computer can be deleted by the owner.
